# Security

PixelGym-OSWorld is research code. The local platform control plane and the MLflow demo UI
have no caller authentication and are intended for loopback use only; see
[deploy/README.md](deploy/README.md). Do not expose or proxy them onto a shared network.

To report a vulnerability, use GitHub's private vulnerability reporting on this repository
(Security tab, "Report a vulnerability"). Do not open a public issue for a security report.
There is no bug bounty.
