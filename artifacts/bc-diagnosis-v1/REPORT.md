## Limits

- The legibility classifier is given each character's position; the policy is not.
- The copy probe's key frames are all distinct, so fitting them can be done by frame identity; it shows capacity, not reading.
- The convergence probe restarts AdamW with zero moments, and its wall-clock cap is checked once per 500-step block, so training can run up to one block past the cap.
- First wrong actions come from closed-loop replays with the stored weights, compared with the oracle plan under the v2 step rule.
