## Interpretation

The instruction names a field ('Click the Company name field'); the request card shows a read-only box with the same label in the same row. A point on that box is a wrong click under the frozen protocol, and it stays one here. The forgiving column only shows how much of the raw-versus-marks gap comes from that one confusable region. It is a post-hoc sensitivity analysis on the same 100 examples, not a pre-registered re-scoring, and the frozen v1 headline is unchanged.
