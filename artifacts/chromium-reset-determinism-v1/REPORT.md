## Terms

- **Semantic determinism**: the reset task record and the privileged DOM form state have the same SHA-256 on every reset. Measured.
- **Bitwise visual determinism**: the RGB frame bytes have the same SHA-256. Measured, within each host and across hosts.
- **Perceptual visual stability**: a tolerance-based similarity. Not computed here; no tolerance is applied to any number below.
